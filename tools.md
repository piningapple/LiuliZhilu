- Universal Dependencies (UD): Это проект, где есть размеченные корпуса на многих языках, включая китайский (UD_Chinese-GSD, UD_Chinese-CFL). Данные размечены по единому стандарту (слова, части речи, синтаксические зависимости).
Что должно быть в данных:
Предложение, разбитое на слова (сегментация).
Для каждого слова — его часть речи (POS-тег).
Для каждого слова — его "родитель" (главное слово, от которого оно зависит) и тип связи (например, nsubj — подлежащее, obj — дополнение, amod — определение и т.д.)
https://universaldependencies.org/
